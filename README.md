# 🏥 Hospital Patient Management System (SQL Project)
## 📌 Project Title
Hospital Patient Management System
## 🎯 Objective
To design a real-world relational database system using SQL Server to manage hospital operations such as:
- Patient records
- Doctor and staff management
- Appointments scheduling
- Admissions and bed tracking
- Billing and payment tracking
- Healthcare analytics and reporting
 🧰 Tools Used
- SQL Server (SSMS)
- SQL (DDL + DML + DQL)
 🏗️ Database Overview
This project is designed with a normalized relational structure including:
- Patients
- Doctors (Staff)
- Departments
- Appointments
- Admissions
- Billing (Invoices)

## 🧾 Tables Description

### 1. Patients
Stores patient personal details.

### 2. Departments
Stores hospital departments like Cardiology, Neurology, etc.

### 3. Staff
Stores doctor details and their department mapping.

### 4. Appointments
Tracks OPD visits between patients and doctors.

### 5. Admissions
Tracks inpatient details and hospital stay records.

### 6. Invoices
Handles billing and payment status of patients.
